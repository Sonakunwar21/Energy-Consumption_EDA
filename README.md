# ⚡ Hourly Energy Consumption EDA

An Exploratory Data Analysis project on hourly electricity consumption data to uncover demand patterns, seasonal trends, and peak usage periods.

</div>

## 📌 Project Overview
- Analyzed hourly electricity consumption from the AEP power system.
- Explored demand variations across hours, weekdays, months, seasons, and years.
- Identified peak demand periods and long-term consumption trends.
- Generated business-focused insights for energy planning and grid management.

## 📂 Dataset
- Source: Kaggle Hourly Energy Consumption Dataset
- Main Features: `Datetime`, `AEP_MW`
- Time-series dataset containing hourly electricity demand records.
- Ideal for trend, seasonality, and consumption pattern analysis.

## 🧹 Data Cleaning & Feature Engineering
- Converted datetime column to proper datetime format.
- Checked and validated missing values and duplicates.
- Extracted time-based features:
  - Year
  - Month
  - Hour
  - Day Name
  - Weekday/Weekend Indicator

## 📊 Analysis Performed
- Univariate Analysis
- Bivariate Analysis
- Multivariate Analysis
- Time-based Trend & Seasonality Analysis
- Correlation & Heatmap Visualizations

## 🔍 Key Insights
- Electricity demand peaks during weekday evenings.
- Winter and summer months show the highest energy consumption.
- Early morning hours consistently have the lowest demand.
- Seasonal and daily usage patterns remain stable across years.

## 🎯 Business Recommendations
- Prepare additional power capacity for weekday evening peaks.
- Strengthen planning for summer and winter demand surges.
- Improve demand forecasting using historical consumption patterns.
- Promote energy efficiency initiatives to reduce peak load pressure.

## 🛠️ Tech Stack
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
  
## ✅ Final Conclusion

This EDA demonstrates that electricity demand follows clear and recurring temporal patterns driven by consumer behavior and seasonal weather conditions.
The consistency of these patterns across multiple years suggests a highly predictable demand structure, providing valuable opportunities for accurate forecasting, efficient resource allocation, and proactive grid management. 
These insights can support utility providers in optimizing power generation, improving operational efficiency, and ensuring long-term grid reliability.
